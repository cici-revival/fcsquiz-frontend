# Запросы к бэкенду

Что нужно от бэкенда, чтобы фронт работал лучше. Пополняется по ходу.

Статусы: 🔴 не начато · 🟡 в работе · ✅ готово

---

## 🔴 Heartbeat в SSE

**Где:** `services/streams/internal/api/rest/handler/` — `game_state.go`, `sse_handler.go`

**Проблема:** сервер пишет в сокет только когда есть события. В затишье между
регистрациями соединение молчит, и прокси рвёт его по таймауту простоя
(обычно 60 с). Для клиента это выглядит как обрыв на ровном месте.

**Нужно:** слать `: keepalive\n\n` каждые 15–30 секунд.

**Почему важно:** затрагивает публичный лендинг. Фронт переподключается
с экспоненциальным бэкоффом, но это лечит симптом, а не причину.

## 🔴 Публичный снимок состава (давай вернем его для перфоманса наверное)

**Проблема:** лендинг получает данные только через SSE. Обычного GET нет:
`/v1/game/registered_teams` под `bearerAuth` и требует обязательные
`season` + `game_number`, а лендинг узнаёт номер игры из самого SSE.

**Нужно:** `GET /v1/game/current_roster` — без авторизации, без параметров,
отдаёт состав текущей игры.

**Даст:** лендинг сможет показать данные сразу и кэшировать их на CDN,
а SSE подключать только для живых обновлений. Снимет постоянные соединения
от посетителей, которые просто зашли посмотреть.

**Приоритет:** ниже heartbeat. Делать по факту нагрузки, не заранее.
